# Contributing

Thanks for helping keep this list useful.

## What belongs here

Tools whose primary job is to **run, orchestrate, supervise, or coordinate AI
coding agents** (Claude Code, Codex, opencode, Cursor, and similar): command
centers, agentic IDEs, multi-agent harnesses and frameworks, terminal
multiplexers, and agent task boards. Adjacent cost or observability tools that
clearly serve agent fleets may go under *Cost & observability*.

Out of scope: single-agent wrappers with no orchestration, prompt or skill
collections, model routers/proxies, and generic LLM frameworks.

## Quality bar

- Real, working, and documented (a README that explains what it does).
- Actively maintained, or at least responsive to issues.
- Not vaporware or a thin re-skin.

## Format

- One tool per pull request.
- Add to the correct section, in **alphabetical order** (case-insensitive).
- Use: `- [Name](https://link) - One concise sentence ending in a period.`
- Link to the project's repository or homepage. No tracking parameters.
- Keep descriptions neutral and factual. No marketing superlatives.
- Ensure your editor trims trailing whitespace.
