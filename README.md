# Awesome Coding Agent Orchestration [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of tools that run and orchestrate fleets of parallel AI coding agents (Claude Code, Codex, opencode, Cursor) as command centers, IDEs, harnesses, and dashboards.

As coding moves from one assistant to many parallel agents working across git worktrees, a new class of tooling has appeared to launch, supervise, and coordinate them. This list tracks the open and notable ones.

## Command centers & ADEs

- [Agor](https://github.com/preset-io/agor) - Orchestrate Claude Code, Codex, and Gemini sessions on a multiplayer canvas with git worktrees.
- [Citadel](https://github.com/SethGammon/Citadel) - Operating layer for Claude Code and Codex with project memory, cost telemetry, and parallel agent fleets.
- [clawport-ui](https://github.com/JohnRiceML/clawport-ui) - Open-source command center for Claude Code agent teams, built on OpenClaw.
- [Helmor](https://github.com/dohooo/helmor) - Local workbench for multi-agent software development.
- [Maestro](https://github.com/RunMaestro/Maestro) - Agent orchestration command center for Claude Code, Codex, and opencode.
- [Mission Control](https://github.com/builderz-labs/mission-control) - Self-hosted orchestration platform to dispatch tasks, run multi-agent workflows, and monitor spend.
- [Orca](https://github.com/stablyai/orca) - ADE for a fleet of parallel agents; run any coding agent with your own subscription, on desktop and mobile.
- [Paseo](https://github.com/getpaseo/paseo) - Orchestrate multiple coding agents from desktop and mobile.
- [PocketPaw](https://github.com/pocketpaw/pocketpaw) - Self-hosted personal AI with a multi-agent command center and a desktop installer.
- [supacode](https://github.com/supabitapp/supacode) - Worktree coding-agents command center for macOS.
- [Superset](https://github.com/superset-sh/superset) - Code editor that runs an army of Claude Code, Codex, and other agents locally.

## Agentic IDEs

- [jat](https://github.com/joewinke/jat) - Agentic IDE with a visual dashboard to supervise 20+ parallel agents.
- [stagewise](https://github.com/stagewise-io/stagewise) - Open-source agentic IDE to create and orchestrate coding agents with app previews and git workflows.

## Harnesses & frameworks

- [agent-orchestrator](https://github.com/AgentWrapper/agent-orchestrator) - Orchestrator for parallel coding agents that plans tasks and handles CI fixes, merge conflicts, and reviews.
- [Babysitter](https://github.com/a5c-ai/babysitter) - Deterministic self-orchestration that keeps agentic workforces on task for complex workflows.
- [Bernstein](https://github.com/sipyourdrink-ltd/bernstein) - Audit-grade multi-agent orchestration for CLI coding agents with signed audit logs and air-gap deploy.
- [claude_codex_bridge](https://github.com/SeemSeam/claude_codex_bridge) - Visible multi-agent CLI workspace for mixing Codex, Claude, Gemini, Cursor, OpenCode, and more.
- [CORAL](https://github.com/Human-Agent-Society/CORAL) - Lightweight infrastructure for multi-agent workflows across Claude Code, Codex, Cursor, and more.
- [Genie](https://github.com/automagik-dev/genie) - CLI agent that plans work, dispatches parallel agents in isolated worktrees, and reviews code first.
- [GoClaw](https://github.com/nextlevelbuilder/goclaw) - OpenClaw rebuilt in Go with multi-tenant isolation and concurrency for agent teams at scale.
- [loushang](https://github.com/zhnt/loushang) - Python agent harness for coding with multi-model orchestration and provider routing.
- [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode) - Teams-first multi-agent orchestration for Claude Code.
- [Omnigent](https://github.com/omnigent-ai/omnigent) - Framework and meta-harness to orchestrate Claude Code, Codex, Cursor, and custom agents with policy enforcement.
- [opencrew](https://github.com/AlexAnys/opencrew) - Multi-agent operating system built on OpenClaw and Slack.
- [ruflo](https://github.com/ruvnet/ruflo) - Agent meta-harness for Claude with multi-agent swarms, adaptive memory, and Claude Code / Codex integration.
- [SWE-AF](https://github.com/Agent-Field/SWE-AF) - Autonomous software-engineering fleet that plans, codes, tests, and ships production PRs.

## Terminal multiplexers

- [amux](https://github.com/mixpeek/amux) - Claude Code agent multiplexer to run dozens of parallel agents via tmux.
- [herdr](https://github.com/ogulcancelik/herdr) - Agent multiplexer that lives in your terminal.

## Task boards & Kanban

- [agent-kanban](https://github.com/saltbo/agent-kanban) - Agent-first task board and mission control for your AI workforce.
- [kandev](https://github.com/kdlbs/kandev) - AI Kanban and development environment to orchestrate agents, review changes, and open PRs.

## Cost & observability

- [ByteCosts](https://bytecosts.com) - Source-linked pricing for thousands of AI models with cost calculators, useful for sizing what a fleet of parallel agents actually costs.
